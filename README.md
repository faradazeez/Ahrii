# Luxury Love Website for Ahriya ❤️

A custom cinematic love story website built from scratch for GitHub Pages.

## Files
- `index.html` . Complete 11-chapter experience with 12+ full-screen visual sections.
- `style.css` . Responsive luxury crimson, black and gold design.
- `script.js` . Stars, particles, floating hearts, reveal animations, live relationship timer, and music controls.
- `assets/` . Reserved for the future photo gallery and music.

## GitHub Pages
1. Upload the contents of this folder to a GitHub repository.
2. Go to Settings > Pages.
3. Select the main branch and root folder.
4. Save.

## Music
Place a royalty-free MP3 named `love-song.mp3` inside `assets/`.
The music button is already wired to it.

## Relationship timer
The timer uses June 18 at 10:29 PM as the start time and automatically uses the most recent June 18 before the current date. This makes the timer work without hardcoding a year.
